# Machine Learning Projects

This repository contains solutions for three distinct machine learning projects based on different types of datasets. Each project focuses on solving a specific problem using machine learning techniques, including classification, regression, and natural language processing (NLP).

## Projects Overview

### Dataset 1: Classification (FARS - US Road Traffic Accidents)
This project focuses on a classification problem using the **FARS** dataset, which contains statistics about US road traffic accidents. The task is to predict the severity of an accident based on 20 features. The dataset has over 100,000 examples, making it a robust challenge for building a predictive classification model.

- **Target Variable:** Severity of the accident
- **Features:** 20 features including various traffic-related statistics

### Dataset 2: Regression (Bacterial Growth Rate Prediction)
In this project, we tackle a regression problem where the goal is to predict the growth rate of a bacteria. The dataset contains experiment results for bacteria grown under different conditions, such as CO2 availability and light exposure. The target variables are the growth parameters of the bacteria, 'a' (maximum number) and 'mu' (growth rate).

- **Target Variables:** 'a' (Maximum number of bacteria), 'mu' (Growth rate)
- **Features:** Number of Cyanobacteria, CO2, Light, Sucrose ratio, Experiment number

### Dataset 3: NLP (News Articles Text Classification)
This project involves natural language processing (NLP) using a dataset containing text from news articles. The goal is to process and analyze the text data, making it ready for tasks such as text classification or sentiment analysis.

- **Feature:** News article text (one per line)
- **Task:** Text classification or NLP-related tasks
